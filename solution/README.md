# Восстановление изображений после сжатия HEVC

На 100 контрольных изображениях средний выигрыш предложенной сети составил **+0,1301 дБ к QECNN** и **+0,3508 дБ к x265**. Пороги из задания равны +0,10 и +0,32 дБ соответственно.

| Обработка | Средний RGB-PSNR |
| --- | ---: |
| Декодер x265 | 24,5169 дБ |
| QECNN из задания | 24,7376 дБ |
| Предложенная сеть | 24,8677 дБ |

## Модель и данные

Предложенная модель — двухмасштабная остаточная CNN с симметрией D4. Она обучена с нуля, без весов QECNN, внешних изображений и дополнительного перекодирования. Группировка RGB-пикселей каждого блока 2 × 2 даёт 12 входных каналов. К ним добавляются 12 каналов локального контраста. Остаточные блоки обрабатывают изображение с половинным и четвертным пространственным разрешением. Предсказанная поправка разворачивается в исходную сетку RGB.

Восемь ветвей применяют один и тот же набор из 150 852 параметров к поворотам и отражениям одного фрагмента. Сеть совмещает их прогнозы в исходных координатах и усредняет. Ошибка рассчитывается один раз по общему результату и одному эталону. Та же операция с восемью ориентациями входит в инференс.

Для обучения используются парные фрагменты 48 × 48. На каждом шаге Adam обрабатывает 12 фрагментов. У ошибки исключаются 4 пикселя по краям, затем MSE фрагмента делится на MSE декодера для его обучающего кадра. Начальная скорость обучения 0,001 уменьшается по косинусному расписанию до значения около 0,00012 за 12 000 шагов. Через каждые 10 шагов обновляется экспоненциальное среднее весов с коэффициентом 0,95. Для итоговой модели выбран чекпойнт с наибольшим покадровым средним PSNR на 20 отложенных изображениях обучающего файла. Официальный тест использовался после фиксации этого правила.

Фактическая длина файла `BSD500train.yuv` соответствует 200 кадрам 480 × 320. На первых 180 парах сеть обучается. Последние 20 используются для выбора весов. Контрольные 100 кадров из файлов `BSD500val.yuv` и `BSD500valc.yuv` используются для итоговой оценки. Имена с `val` соответствуют тестовой части в этой версии репозитория. Применены готовые декодированные кадры. Прилагаемый к заданию скрипт кодирования указывает `--crf 35 --keyint 1`.

## Файлы

- `restore.py` содержит модель и команды обучения, оценки и обработки изображений.
- `support.py` читает YUV, воспроизводит QECNN и вычисляет метрики.
- `phase_restorer.pth` содержит готовые веса предложенной сети.
- `results/per_image.csv`, `results/summary.json` и `results/psnr.png` содержат покадровые значения, сводку и график. В `results/examples/` лежат полные кадры и одинаковые фрагменты для трёх характерных случаев.
- `training.csv` содержит историю проверки на отложенных 20 кадрах. В `report.pptx` можно заполнить поля автора, группы и репозитория, затем экспортировать презентацию в PDF.

## Запуск

Используйте исходный учебный проект с четырьмя каталогами YUV и исходным файлом `best_model2026.pth`. Проверенная версия исходного проекта — коммит `af78856948403c3cce7705eb2d7f52f6f44a6824`. [Репозиторий задания](https://ctlab.itmo.ru/gitlab/eabelyaev/cnnimagequalityenhancement)

Распакуйте архив в корень этого проекта. Должна получиться следующая структура.

```text
cnnimagequalityenhancement/
  best_model2026.pth
  trainrawyuv/BSD500train.yuv
  traincompyuv/BSD500trainc.yuv
  testrawyuv/BSD500val.yuv
  testcompyuv/BSD500valc.yuv
  solution/
    restore.py
    support.py
    phase_restorer.pth
    requirements.txt
```

Проверено с Python 3.12.10. Все команды ниже выполняются из `solution`. Установите зависимости в виртуальное окружение командой `python -m pip install -r requirements.txt`. Параметр `--device auto` выбирает CUDA, MPS или CPU в порядке доступности. Можно задать устройство явно.

**Воспроизвести сравнение на всех 100 изображениях**

```sh
python restore.py evaluate --root .. --out reproduced
```

**Обработать декодированный YUV420p без эталонов и сохранить RGB-кадры в PNG**

```sh
python restore.py enhance ../testcompyuv/BSD500valc.yuv --out enhanced
```

Команда принимает файл планарных 8-битных кадров 480 × 320 в порядке Y, U, V. Эталонные изображения и веса базовой QECNN нужны только для команды сравнения.

**Повторить обучение с нуля и оценить новые веса**

```sh
python restore.py train --root .. --weights trained.pth
python restore.py evaluate --root .. --weights trained.pth --out retrained-results
```

При обучении фиксируются генераторы случайных чисел. Повторное обучение на другом устройстве может дать немного иные веса и PSNR.

## Метрика и примеры

U и V увеличиваются функцией OpenCV `INTER_CUBIC` в формате uint8. Коэффициенты преобразования в RGB совпадают с исходной работой. Для каждого кадра считается `PSNR = −10 log10(MSE + 1e−10)`, где MSE — среднее по всем пикселям и каналам в диапазоне [0, 1]. Сравнение проводится до округления в PNG. Ограничение RGB на выходе предложенной сети входит в её функцию предсказания. QECNN вычисляется с исходным постпроцессингом.

График и CSV сохраняют порядок кадров в файле, нумерация начинается с 1. Примеры выбираются по минимальной, ближайшей к медиане и максимальной разнице PSNR с QECNN. Рамка в `location.png` отмечает фрагмент 96 × 96 с наибольшим средним квадратичным расхождением между двумя прогнозами. Оценки под фрагментами в отчёте относятся ко всему кадру.
